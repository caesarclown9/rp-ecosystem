## 7. Зоны разрыва (потенциальные точки «бардака»)

| # | Зона | Симптом | Модуль решения |
|---|---|---|---|
| 1 | Группа из 3 юр.лиц | Консолидация P&L через ручную сверку 1С | Master Data Hub (RedStaff Этап 2 + будущий бухгалтерский контур) |
| 2 | 1С:ЗУП vs RedStaff Этап 1 | Источник правды не зафиксирован → ошибки начислений при смене должности | RedStaff Этап 2 (Master Data Hub) |
| 3 | Колл-центр 0800 vs RedPay vs OCPP | Клиент звонит в 0800 — оператор не видит статус ЭЗС в real time | ИИ-ассистент клиента (КП ИИ-агентов, модуль 2) |
| 4 | Табель операторов АЗС | СКУД не на всех точках → удалённые АЗС в Excel | RedStaff Этап 3 (Табель + СКУД + GPS) |
| 5 | Тендеры на госплощадках | Закупщик не успевает мониторить → пропуски релевантных тендеров | ИИ-агент по тендерам (КП ИИ-агентов, модуль 5) |
| 6 | Сметы новых АЗС | 3–4 недели на смету → решения медленнее рынка | Сметный ИИ (КП ИИ-агентов, модуль 6) |
| 7 | Юр.отдел | Тысячи договоров (B2B, аренда участков под АЗС, страховщики) | ИИ-юрист (КП ИИ-агентов, модуль 4) |
| 8 | Логистика топлива | «Сухие» резервуары / замороженные деньги без точного прогноза | ML спроса (КП ИИ-агентов, модуль 7) |
| 9 | Маркетинг RedPay | Массовые скидки всем → бюджет горит | ИИ-маркетолог (КП ИИ-агентов, модуль 8) |
| 10 | EV-направление | Узнаём о поломке коннектора через жалобу клиента | ИИ-аналитик ЭЗС (КП ИИ-агентов, модуль 9) |
| 11 | Биржа + кредит = публичность | Требования к прозрачности отчётности возрастают | Observability + журнал интеграций + compliance модули из всей экосистемы |
