# RP Ecosystem

Концепция единой корпоративной экосистемы для группы компаний **Red Petroleum / Альфа Ойл**, подготовленная **ASYSTEM**.

Интерактивный демонстрационный сайт без бэкенда — статический HTML + Tailwind CDN + Alpine.js + D3.js + Chart.js + GSAP. Деплой через GitHub Pages.

## Что внутри

- `index.html` — основной сайт с секциями: Hero, факты, корпоративная карта группы, точки разрыва, видение экосистемы, модули, контакт
- `assets/css/styles.css` — кастомные стили поверх Tailwind
- `assets/js/main.js` — скролл-анимации и интеракции
- `docs/research_report.md` — источник истины: консолидированные публичные данные о группе компаний, IT-стек, операционные контуры, финансовый профиль, источники

## Источники данных

Все цифры и факты — публичные. Источники перечислены в `docs/research_report.md`.

Внутренние ASYSTEM-документы (НЕ публикуются):
- ТЗ RedStaff Этап 2 от Заказчика
- Договор RedCharge (Google Doc)
- КП ASYSTEM по 9 ИИ-агентам
- Стратегия ЭЗС Кыргызстан для Минэнерго

## Деплой

Сайт развёртывается на GitHub Pages автоматически из ветки `main`:
- Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)`

Файл `.nojekyll` отключает Jekyll-обработку (статика отдаётся как есть).

## Лицензия

Подготовлено для частного использования между ASYSTEM и Red Petroleum / Альфа Ойл. Не распространять без согласования.
